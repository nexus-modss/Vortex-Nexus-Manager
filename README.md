# Vortex Mod Manager (v2.10.1)

Official Nexus Mods desktop organizer for Skyrim, Fallout, Cyberpunk, and Baldur's Gate 3 with automatic store discovery and LOOT sorting.

## Highlights in 2.10.0 / 2.10.1
| Feature | What Changed |
| --- | --- |
| Detected Installed Games | Auto-scans Steam, GOG, and Epic libraries with store badges before extensions install |
| Redesigned Mods Table (Beta) | Custom columns, thumbnail hover cards, pinned toolbar actions, and Collection grouping |
| `Apply` Workflow & Collection Guard | Replaces `Deploy` next to Play and warns before updating mods locked to a Collection |
